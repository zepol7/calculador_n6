# 🧮 Calculadora en Python

Calculadora sencilla desarrollada en Python que permite realizar operaciones aritméticas básicas desde la consola.

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![Versión](https://img.shields.io/badge/versión-1.0.0-green)
![Licencia](https://img.shields.io/badge/licencia-MIT-lightgrey)

## 📋 Descripción

Este proyecto es una calculadora de línea de comandos creada con fines académicos. Permite al usuario ingresar dos números y elegir la operación que desea realizar, mostrando el resultado en pantalla.

## ✨ Funcionalidades

- ➕ Suma
- ➖ Resta
- ✖️ Multiplicación
- ➗ División (con validación de división entre cero)
- 🔁 Menú interactivo para realizar varias operaciones seguidas
- ⚠️ Manejo de errores ante entradas no numéricas

## 🛠️ Requisitos

- Python 3.8 o superior
- No requiere librerías externas

Verifica tu versión de Python con:

```bash
python --version
```

## 🚀 Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/USUARIO/calculadora_git.git
```

2. Entra a la carpeta del proyecto:

```bash
cd calculadora_git
```

## ▶️ Uso

Ejecuta el programa con:

```bash
python calculadora.py
```

Ejemplo de ejecución:

```
===== CALCULADORA =====
1. Sumar
2. Restar
3. Multiplicar
4. Dividir
5. Salir
Elige una opción: 1
Ingresa el primer número: 8
Ingresa el segundo número: 5
Resultado: 13.0
```
